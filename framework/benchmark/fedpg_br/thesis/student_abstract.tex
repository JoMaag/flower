\begin{abstract}
Federated Reinforcement Learning (FedRL) enables multiple agents to collaboratively
learn a shared policy without exchanging raw experience data, making it attractive
for privacy-sensitive and distributed control applications. Despite growing theoretical
interest, the field lacks a standardised and reproducible testbench that allows
researchers to evaluate and compare algorithms under identical conditions.

This thesis presents the \emph{Flower FRL Benchmark}, an open-source framework for
federated policy gradient research built on the Flower federated learning platform.
The benchmark provides a complete implementation of FedPG-BR --- a Byzantine-robust
federated policy gradient algorithm --- together with SVRPG and a plain averaging
baseline. A decorator-based strategy plugin system allows researchers to register a
custom aggregation algorithm in a single Python file and have it immediately available
for experimentation without modifying any framework code. The system further supports
simulation of seven Byzantine attack types, standard discrete and continuous control
environments, and a real-time web dashboard for live experiment monitoring.

Through empirical evaluation we characterise the interaction between FedPG-BR's
probabilistic Byzantine filter and policy learning dynamics across environments. We
identify and explain a phenomenon in which the filter increasingly suppresses honest
agents as training progresses --- a consequence of rising gradient variance in improving
policies --- and discuss its implications for hyperparameter selection and algorithm
choice. The benchmark is distributed as a reproducible Docker image and is designed
to lower the barrier for academic research in federated reinforcement learning.
\end{abstract}
